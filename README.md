# 感想
OSC大阪でISHI会に出逢ってから、やってみたいと思っていたところ北陸編が開催されると聞いて参加してきました。<br>
※決断するにあたりOSC京都の懇親会で、今回の講師を務めていただいた大野さんと話せたのは大きかったです。

開発環境をWSL2のイメージで用意していただいてたので、とても手軽に始めることができました。<br>
はまった点は以下の2カ所<br>
+ Podmanを入れていたのでHomeだと「wsl -d ubuntu2204_ishi-kai_EDA」でアタッチを切り替える必要がある
+ ユーザーでインストールされているのため「su isi-kai」で起動前にユーザーを切り替える必要がある

「xschem」の回路図の作図は、「BSch3V」以来何年ぶりだろうという感じでしたが、全体移動以外は直感的に触れてとてもスムーズに作業できました。<br>
「klayout」による作図はちょっと癖があり色々と講師の方々にお手数をおかけしましたが、大昔のイラストレータより素直かなっといった感じでした。<br>

DRCチェックもVLSチェックも講習時間内に無事通せて、初めての作品を完成させることができました。<br>
ありがとうございました。<br>

1ビットCPUがとても気になりますが、アナログ回路でなにかできないか妄想しています。<br>
機会があればもっと大きなものにも挑戦したみたいと思っております。<br>

講習会の説明もとても丁寧で、層になっているところでどのようにNMOSが乗っていくかなどイメージをつかむことができた気がします。<br>
チップ受け取りの会場によっては参加できないかもしれませんが、できれば会場で受け取って動作確認をしてみたいです。<br>
よろしくお願いします。
